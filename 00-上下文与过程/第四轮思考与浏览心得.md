## 1 开局：被自己的护栏拦在门外（00:25–00:40）

本轮第一个动作是读**档案根目录**，被沙箱守卫（PreToolUse 钩子）机械拒绝：第三方模型通道只允许在 `custom-models-sandbox` 内活动。尝试了对话内授权（用户选了「授权访问并继续」）与沙箱豁免参数，均无效——**钩子只认路径，不认对话授权**。

当时的判断：不绕过安全机制（这是对的），读钩子文档弄清机制，向用户说明两条解锁路径，同时**不空等**——先做不受限的网络检索。这个插曲后来成了 Q-15 的元教训：护栏要硬、但要有紧急开关；「用户授权后的临时白名单」是缺失的一环。用户随后手动解除（「钩子已解除」），恢复访问。

**沙箱期的产物**：14 份材料的检索与一手核对完成，批注草稿 Q-01…15 写出——但锚点全部按章节主题**猜测**，草稿头部如实声明了这一点。这个声明后来救了本轮：它让「哪些判断需要重验」一目了然。

## 2 检索路线：先找「知名」，再找「增量」（00:40–01:00）

选材标准（对应「知名材料」）：同行评审论文（ICML/USENIX/CHI）、官方报告（METR/DORA/OpenAI/Stanford）、一线实践者原文（Willison/Osmani/Yegge）。刻意避开二手营销号作论据，但用汇编站（aidlc.guru、edgechat、bestblogs）当**线索雷达**——约 60% 的新线索来自它们，每个关键数字再回一手核对。

几个检索中的发现，按冲击排序：

1. **DORA 官方计算器页是本轮最值的一次回查**。原 URL（dora.dev/research/ai/roi/）404，改道找到官方 PDF 与计算器页；计算器里 **J-Curve productivity drop (%) 和 timeline (months) 是正式输入框**——J 曲线不是博客叙事，是官方模型的结构件。这一下把手册里 B/C 级的「验证税」升成了 A 级，也给了 J5 一个同构的官方背书。
2. **SO 官方博客与原始问卷页数字归属互换**（45%/66% 写反）。第一反应是「手册可能引错了」，标了 P0——后来通读发现手册引用正确，存疑清单早就登记了这个混用。**官方自己都会打架，数据必须锚定原始页。**
3. **BaxBench 的 62% 被广泛误引为漏洞率**（实为功能正确率，正确者中约半数可被利用）。这类「流传中变形」的数字是引用卫生的头号敌人。
4. **Stanford 金丝雀三版本三数**（13/16/19%），METR 时间地平线三个时间窗三个数（196/130.8/88.6 天）——**版本漂移比结论反转更常见也更隐蔽**。直接催生了来源总表 L 组的「版本+口径」强制列。
5. **厂商自审是最被低估的来源**：OpenAI 自己审出 59.4% 测试缺陷、自己停报 Verified；METR 自己写「50% 不是部署阈值」；DORA 自注「高不确定性估算」。利益相关方的自我限定，比第三方吹捧可信得多。
6. Osmani 的 URL 猜错两次（/the-orchestration-tax/ 与 /dont-outsource-the-learning/ 均 404），搜索纠正为 /orchestration-tax/ 与 /dont-outsource-learning。**猜 URL 的成本比多搜一次高。**

## 5 个人开发者视角：这轮材料真正改变了什么

手册与速查卡已把单人纪律覆盖得很全（WIP=1、三条反对、隔夜冷读、抽查验证器、五行交接、敢删）。本轮新材料带来的**行为增量**只有九条（详见个人建议文件），核心三条：

1. **J 曲线学费**（DORA）：头三个月更慢是正常的，判断标准是验证能力有没有在涨——这直接改变「要不要放弃」的决策时点。
2. **姿态与顺序**（Anthropic 组内分层 + CHI）：先写自己的假设再问 AI；交付与学习是两个指标——这改变每次提问的前置动作。
3. **装包三查 + agent 自动 install**（Spracklen 链条）：单人没有安全团队，依赖幻觉是少数「一次中招就不可逆」的风险——这改变装包这个具体动作。

其余（方案优先分工、先红后绿、批量审查、黄金判据、职业校准、个人三笔账）是既有纪律的强化或新证据背书。**不重复已有条目**是本轮个人建议的写作纪律——个人版卡 80 行上限本身就是对「建议膨胀」的护栏。
