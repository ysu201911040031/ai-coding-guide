# AGENTS.md · Ai使用与开发空间

## 这个空间做什么

沉淀「**用 AI / Agent 写代码**」的可执行准则与通用配置，**不绑定任何具体项目**。
资料根目录在**上一级**（手册、两张速查卡、分类资料档、资源台账、发布包）。本文件不写死绝对路径——换机器即失效。
**手册版本号一律以文件头为准，不在此处写死**（本行原写「v3.3」，实际已迭代多版——易变事实进检查不进规则）。

## 运行时 vs 档案（2026-11-12 新增）

- **运行时**（每次会话读、每天看）：本文件 + `../速查卡-个人版.md` + 协作铁律 + 项目自己的 AGENTS.md。
- **按需运行时**：`../资料速查表.md` —— **要写新功能/找轮子/装库前打开**（D8 复用优先）。不是每次会话读，是「动手找之前」读。
- **档案**（出事才查、季度复审）：主手册全文、五层审阅批注、`01`–`09` 分类资料。
- **半运行时**：`../10-资源台账/`（用到某资源时查一行、更新一行）。
- 判据：**一个月没被打开过的文件，不该出现在「开工先读」里**。收工时按铁律第 12 条报一行「本次实际用到 / 未打开」，三次会话后据此复审降级。

具体项目的规则与记忆**一律不进本空间**。需要项目实例时去该项目自己的工作区找；
**不要**把某个项目的构建命令、硬件铁律、框架版本约束当成通用结论写进来。

## 开工先读这三份

1. `记忆/MEMORY.md` — 记忆索引（项目现状 / 全程日志 / 审阅纪律 / 脚本坑 / 协作偏好）
2. `../99-本机专用/交接-2026-11-11.md` — 做到哪、下一步、坑、别碰、验收
   （**本机专用件，不随包分发**；拿到脱敏包的读者没有这份，改读 `记忆/MEMORY.md` 与本目录 README）
3. `../速查卡-个人版.md` — 单人开发节奏卡（按时间尺度排；**有 v2 候选版待试用裁决**）

需要完整历史时看 `会话记录/` 下**带 `-v2` 后缀的可读版**（33 轮，23:32 快照，最新）；19:36 的 29 轮旧版保留在同目录不带 `-v2` 的文件里。
文件名含会话标识，**用通配匹配而不是抄全名**：`会话记录/*-可读版-v2.md`。

## 硬约束（不遵守就会出事级别）

- **自检先请示**：编译、测试、lint、截图、跑应用——先说「跑什么·验什么·影响面·耗时」再执行。纯读取不受限。
- **破坏性动作人工批**：删除、覆盖、force push、drop 表、生产变更，先确认再动手。
- **做减法必须保留原稿**：任何精简版 / 新版本 / 速查卡**一律新建文件，绝不覆盖**；封存件记 SHA-256；被删章节列「章节号 + 一句理由」。封存清单**最后生成**、纯校验格式、**实跑** `sha256sum -c`，清单自身哈希锚在封存目录之外。
- **验收标准先写死**，再动手；说不出「它怎么坏」不算完成。验收判据必须与生成判据**不同源**——自己出题自己答等于没验。
- **易变的事实进检查，不进规则**：分支名、未提交数、版本号一律实测，不要写死。
- **不确定就问，别猜运行期事实**。
- **先找再写（D8）**：写新模块/引依赖/装 skill 前，先查 `../资料速查表.md`；表里没有再搜，搜到必回 **github.com 一手**核兼容与许可。**star 数不作判据**（实测二手站差 3 倍）；**先确认本项目的目标环境（框架版本/OS/架构/工具链/许可政策），再按它筛库**——目标环境是项目参数，不写死在任何通用文件里。新建须能说清「查过哪些候选、为什么都不合适」。搜 20 分钟无果就自己写。

## 输出偏好

- 结论具体、可对照执行；数字标 **A/B/C 可信等级** 与 🟢稳定 / 🟡时点 / 🔴易变。
- 未核实的来源**只写方法特征，不编原话**。
- 长文档审阅先报三个数（总行数 / 条目数 / 表-文映射差集），再给意见——**禁止抽样**。
- 深度任务先给计划按计划走；「再次思考」= 证伪自己上一轮的规矩，不是重述。
- 调研产物默认四件套：**主交付 + 分类资料档 + 来源索引 + 上下文/思考结论**，原件能下载就存档。

## 记忆维护

- 活的那份在 `记忆/`（本目录，随档案走）。
- 工具自动加载的通常是**用户目录下该工具自己的 memory 目录**，路径因工具与机器而异：
  `<用户目录>/<工具配置目录>/projects/<工作区标识>/memory/`
  —— **首次使用时实测确认一次，把结果记在本机的私有笔记里，不要写进本文件**（本文件要分发）。
- **改完 `记忆/` 后同步一次**到上面那个实测路径（用 `cp` 覆盖同名文件即可）。
- 索引 `MEMORY.md` 每条一行、不超过 150 字符；正文写在各自文件里，不要塞进索引。
