## 记忆有两份，改哪份

| | 路径 | 角色 |
|---|---|---|
| **源头** | `对话/记忆/` | 随档案走，人可读可改，**改这里** |
| 镜像 | `<用户目录>/<工具配置目录>/projects/<工作区路径转写>/memory/` | 应用自动加载的那份 |

改完源头同步一次（**先把两个变量填成本机实测值**，实测值记在私有笔记里，别写回本文件）：

```bash

mkdir -p "$DST" && cp "$SRC"/*.md "$DST/"
```

## 重新导出 + 脱敏（两步）

会话仍在原工作区运行时，导出的是**当时快照**。目前本空间有两份快照，文件名带 `-v2` 的是新的：

| 快照 | 记录 | 轮数 | 落盘 |
|---|---|---|---|
| 2026-11-11 19:36 | 1561 行 | 29 | `-可读版.md` / `-思考记录.md`（2 个压缩点） |
| 2026-11-11 23:32 | 3006 行 | 33 | `-可读版-v2.md` / `-思考记录-v2.md`（3 个压缩点） |

⚠ **自指陷阱**：导出动作本身也会进记录，每重跑一次段落数就涨；计数必须标明是哪一次快照。

```bash
# 每次刷新都建新目录、新后缀；19:36 封存目录只读，不要往里写
A="<用户目录>/<工具工作区>/<工作区标识>/<工具配置目录>/会话存档/2026-11-11-AI开发规范-刷新-<时间>"
S="<档案根>/对话/会话记录"
SRC="<用户目录>/<工具配置目录>/projects/<源工作区路径转写>/<会话标识>.jsonl"
SFX="-v3"   # 本空间落盘后缀，绝不与已有文件同名

# 1 导出到项目存档（只读源会话，不改应用状态）
#   产出 <日期>-<会话标识>-{原始记录.jsonl, 可读版.md, 思考记录.md}
D="<日期>"; ID="<会话标识>"       # 与源文件名一致，实测填入
python "$S/export-session.py" "$SRC" "$A" "<会话标题>"

# 2 脱敏进本空间（输入=存档未删节版，输出=带后缀的新文件，不覆盖原件）
PAT="<用户目录>/<工具工作区>/<工作区标识>/<工具配置目录>/会话存档/2026-11-11-AI开发规范/项目脱敏模式.txt"
for n in 可读版 思考记录; do
  python "$S/redact-project.py" "$A/$D-$ID-$n.md" \
    "$S/$D-$ID-$n$SFX.md" "$PAT" "$A"
done
```

> 19:36 那份快照在存档里带 `-未删节` 后缀；重跑会生成**不带该后缀的新快照**，两者并存，别混。
> 导出末尾几轮就是迁移与通用化本身，所以新快照的段落数一定比旧的多。

脱敏按空行分段，命中即整段替换为一行标记，其余**逐字保留**；连续标记会合并。
模式表每行一个正则，行首 `!` 表示区分大小写。脚本退出码 2 = 仍有残留。
