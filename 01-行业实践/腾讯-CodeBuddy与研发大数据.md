## 2. 分业务线归因（最值得借鉴的部分）

| 业务线 | 做法 | 结果 |
|---|---|---|
| 微信后台 | 分布式编译工具链 | 编译耗时 −50% |
| 微信支付 | 全流程研效改造 | 需求交付周期 −31%，发布质量 +14% |
| 手机 QQ | iOS 构建优化 | 编译构建耗时 −40% |
| 腾讯云 | CodeBuddy 深度使用 | 65% 新增代码来自 CodeBuddy，人均千行 Bug 率 −31.5% |
| 腾讯游戏 | 美术制作自动化 | 自动化率 95% |
| 腾讯广告 | 发布流程自动化 | 迭代效率 ×2，90% 版本发布全流程自动化 |
| 腾讯金融科技 | 环境部署 | 成功率提升至 99% |

**可迁移点**：把指标按业务线/环节拆开（编译、交付周期、Bug 率分别量化），而不是给全公司一个笼统的「提效 20%」。

## 3. 平台与工程化配套

- **WeDev 研效平台**：每日跨工具数据互通 8000 万+ 次，月均节省手工操作 530 万次。
- **AnyDev 云研发平台**：环境准备从 1 天压缩到 1 分钟。
- **AI 用在评审与测试，而不只是补全**：AI 评审参与度 94%、AI 预审发现并被采纳的缺陷占 28%。这与手册 C4「把预算的一半放在下游」一致。
- **分语言生成率**（CSIG 技术白皮书口径）：Go 40.0%、C/C++ 37.6%、Java 37.5%、Python 34.9%、JS/TS 28%；单行补全端到端约 400ms，私有化单卡 L20 约 50 tokens/s。
- **基于 MCP 的多智能体架构**：对接企业既有工具链，支持跨文件协同修改（AST 定位 + 多文件编辑）。
- **测试环节**：手工用例生成准确率 35%–50%，直接应用率 20%，综合采纳率 45%（腾讯内部实践数据）。

## 4. Harness Engineering 三级演进（腾讯云对 500 人规模团队的框架，B/C 级）

| 级别 | 形态 | AI 参与度 | 人的角色 |
|---|---|---|---|
| L1 | 辅助 | 低 | 主导编码 |
| L2 | 1+n 人机协同 | 50% | 协同决策 |
| L3 | 全自动化交付（Agent + MCP 闭环） | 80% | 只保留准入审核与异常干预 |

同一来源给出的环节级实测（B/C 级，未经独立验证）：AI 生成有效代码采纳率平均 54%（区间 30%–75%）；单测覆盖率 >90%、执行效率 10x（2–3 天 → 2 小时内）；代码评审周期 10x（1 天 → 1–2 小时）；需求分析 3–5x；方案设计 1–3x。

> 该表与手册 B1 的「按风险选协作模式」形成对照：**L3 之所以还留着人，是因为准入审核与异常干预不可自动化**——与 A3、D2 一致。

## 5. 自举案例：CodeBuddy Code（B/C 级，媒体转述）

- 4 名研发、58 天、79 个版本，其中 **90% 上线后新增代码由 CodeBuddy Code 自己生成**。
- 2026 年 1 月披露：CodeBuddy Code 覆盖腾讯 1.2 万工程师；腾讯高管在 WEF 表示「CodeBuddy Code 的 90% 代码由 CodeBuddy 生成」。
- 产品能力侧：Plan 计划模式、ACP 协议、自定义 Subagents、Hooks、插件市场、隔离沙箱、Skills、企业版安全审计与研效度量。

**解读**：这是「工具自举」的极端案例，不等于一般业务系统可以照搬。更值得抄的是它把 **Plan 模式、隔离沙箱、审批钩子**做进产品——对应手册 B3、A3、D7。

## 6. 外部客户侧数据（B/C 级）

某头部寿险：研发提效 18%、AI 生成代码 60 万行+、600+ 人日常使用、累计使用率 90%。企业客户典型区间：编码时间缩短 40%+、AI 生成代码占比 40%+、研发提效 16%+。

Gartner 2024-08 首份《AI 代码助手魔力象限》收录腾讯云，并预测「到 2027 年，使用 AI 技术的开发团队将从 5% 增至 40%」。

## 7. 对本手册的贡献与不采纳部分

| 采纳 | 不采纳 |
|---|---|
| 分业务线归因（C4 / E1） | 「整体研发效能 +20%」作为通用预期 |
| AI 同时投入评审与测试（C4） | 不同年份口径的 AI 代码占比做对比（E1） |
| 平台化配套（环境准备、数据互通）作为「流程先于工具」的例证（B6 / E3） | Harness L3 的 80% 参与度当作目标值 |
| Plan 模式 + 沙箱 + Hooks 的产品化（A3 / B3） | 客户案例中的提效百分比作为因果证据 |
