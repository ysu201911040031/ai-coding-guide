# 资源台账 · 总索引

> 建立：2026-11-12 ｜ 依据：手册 **D9 资源台账** + 协作铁律 **第 11 条**
> Provenance：AI 生成（模型产出，人工未改动）
> **纪律**：凡查必登、凡用必更。每次使用更新「次数 + 最近使用」，并按「只记两端」写评分条（txt，30 秒）。

## 一、目录结构

```
10-资源台账/
├── README.md              本文件：怎么用、怎么淘汰
├── 资源总表.md            全部资料/库/网站/媒体，一行一资源（主索引）
│                          A 官方 / B 研究 / C 实践者 / D 中文社区
│                          E 需账号 / F 已淘汰 / G 可复用轮子
├── 提示词库索引.md        外部提示词：三筛 / 快照 / 检索顺序（快照在 99-本机专用）
└── 评分表模板.txt         每次使用的评分格式（复制即用）

../资料速查表.md           ← 开发前查这里（运行时，按用途分区 + 目标环境兼容/许可硬筛 + 坑）
```

**另外两样请在你自己的私有目录里建**，本仓库只给格式与规则，不带任何人的实际使用数据：

| 你自建的文件 | 放什么 | 为什么不随仓库分发 |
|---|---|---|
| `skill台账.md` | 已装/已用的 skill 与插件，含**权限范围**与风险 | 等于一份「我装了什么工具、开了什么权限」的画像 |
| `使用记录/YYYY-MM.txt` | 按月一个 txt，追加式、不覆盖 | 逐次使用记录是个人工作痕迹 |

> 这两样是台账真正产生价值的地方（**权限审计**与**淘汰依据**），但它们的价值恰恰来自「记的是你自己」——
> 所以**规则公开、数据私有**。照上表建空文件即可，字段沿用下面第三、四节。

分类归档仍在既有目录（`01-行业实践` / `02-开源经验` / `03-研究结论` / `08-外部读物` / `09-大神经验`），
**本台账只做索引与使用统计，不搬家、不复制原件**——避免两处内容打架。

### 速查表 vs 台账（别记两遍）

| | `../资料速查表.md` | 本台账 |
|---|---|---|
| 回答 | **开发前查什么** | **用过什么、值不值得再用** |
| 组织 | 按用途（API/提示词/C++/Qt/学习/工具） | 按来源类型（A–G） |
| 特有 | **兼容与许可硬筛、踩坑清单** | 次数、最近使用、评分、淘汰 |
| 何时动 | 发现新轮子 / 状态变了 | 每次实际使用 |

**G 组是两表的接缝**：速查表里的每个轮子在总表 G 组有一行编号，用途只在速查表写一次。

## 二、三条使用规则

1. **凡查必登**：检索到有价值的资料/库/站点，当场登记一行（URL + 语言 + 是否需登录 + 等级 + 版本口径）。
   一次检索命中多个，只登记**真正读过或用过的**，不登记搜索结果列表。
2. **凡用必更**：每次使用（读一篇、装一个库、跑一个 skill）→ 总表 `次数+1`、更新 `最近使用`。
   **只记两端**：评分 **≥20 或 ≤9 或有风险** → 到 `使用记录/YYYY-MM.txt` 追加评分条；
   **15–19 分只更新总表，不写评分条**。
   > 为什么：台账的两个目标是「下次少走弯路」和「淘汰垃圾」，都只需要两端数据。
   > 要求每次都写评分 = 每天 5–10 分钟纯记账，**必然烂尾**（手册 M1：加检查要说清从谁的预算里扣）。
3. **半年复审**：连续 3 次评分 ≤2 或半年零使用 → 标 `候选淘汰`；复审决定删除或降级。**删除前保留记录**（只新增不覆盖）。

## 三、评分怎么打（5 维，各 1–5 分，30 秒）

| 维度 | 1 分 | 5 分 |
|---|---|---|
| **有用** | 没解决问题 | 直接解决核心问题 |
| **准确** | 有错/过时/幻觉 | 与一手核对一致 |
| **省事** | 读完还得自己重做 | 拿来即用 |
| **可信** | 无出处营销文 | 官方/论文/可复现 |
| **复用** | 一次性 | 会再用/已进规则 |

**总分 = 五项之和（5–25）**。≥20 优质优先复用；15–19 可用；10–14 谨慎；≤9 候选淘汰。
**一票否决**：出现幻觉包名、要求超范围权限、凭据泄露风险 → 无论总分直接标 `风险`。

## 四、字段约定

- **等级**：沿用 `06-来源索引` 的 A（一手可回查）/ B（机构自报、可信解读）/ C（二手转述）。
- **需登录**：`否` / `需账号`（用户提供，**凭据不写进台账**）/ `部分`（免费额度+付费墙）。
- **语言**：中 / 英 / 日 / 其他，不限区域。
- **版本口径**：有版本号或统计口径的必填（第四轮 Q-15 教训：无版本口径的引用半年失效）。

## 五、从空表开始（3 步）

1. **读 `资源总表.md`**：里面是已登记的外部资源（官方文档 / 论文 / 开源仓库），可以直接拿去用。
   凡是你实际用了的，按第二节把 `次数` 与 `最近使用` 更新到**你自己的副本**里。
2. **建 `skill台账.md`**（私有）：把你已装的 skill / 插件逐个登记，重点写**它申请了什么权限**。
   这一栏比「好不好用」重要——超范围权限是一票否决项。
3. **建 `使用记录/<当前年月>.txt`**（私有）：复制 `评分表模板.txt`，只在两端时追加。

> **不要一上来补历史记录。** 从今天起记，三个月后就有淘汰依据了；
> 试图回忆过去半年用过什么，是台账烂尾的第二大原因（第一是要求每次都写评分）。
