## AI 协作铁律（由 setup.sh 写入，2026-11-11）

- **自检先请示**：编译 / 测试 / lint / 批量审计 / 截图比对，先说「跑什么·验什么·影响面·耗时」，等确认才执行。
- **开工先报基线**：路径 / 分支 / 未提交文件数，以 `git status` 实测为准（规则里写的可能是旧的）。
- **破坏性动作先批**：删除、reset --hard、push --force、部署、改生产数据、发外部消息 → 先列清单 + 回滚方式。
- **验收先写死**：3–5 条可复核条目，缺证据 = 未完成。
- **只新增不覆盖**：做减法前先封存原稿，删了什么要留清单。
- **引用数字必带**：样本 / 口径 / 年份 / 是否相关性。
- **一次给一个方案 + 理由**；要多个备选请明说。
- **不确定就问**，不猜运行期事实（全局量实际值、硬件时序、现场行为）。
