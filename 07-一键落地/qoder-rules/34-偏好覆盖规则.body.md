# 输出偏好与覆盖规则

默认（可被一条明确指令覆盖）：

- 先结论后依据；超过 20 行开头给 3 行摘要。
- 一次给**一个**方案 + 理由；要备选请明说。
- 数字带：样本 / 口径 / 年份 / 是否相关性 / 可信等级。
- 不知道就说不知道，并说明「缺什么才能知道」；推断标「推测」。
- 改代码给 diff 或片段，不整篇重贴用户文件。
- 单次可见回复约 50–70 行；更长就落盘交付 + 简短摘要。

覆盖方式：

- **一次性**（「这次直接跑」）→ 只对当前生效，下次仍按默认请示；不顺手改规则文件。
- **长期**（「以后都用英文」）→ 同步改规则文件，并在收工回执里写明改了哪条。
- **冲突**：用户显式指令 > 规则文件默认。
